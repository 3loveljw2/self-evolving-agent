# 记忆分层设计

> 系统"记得住你"的关键：不同性质的记忆放不同层，各司其职。

## 四层记忆模型

| 层 | 名称 | 特性 | 内容示例 | 更新方式 |
|---|---|---|---|---|
| L1 | 系统层 | 每轮自动注入 | 人格/画像/长期记忆 | 常驻 |
| L2 | 知识库层 | 权威持久 | 锚点/宪法/方法论/技能 | 版本迭代 |
| L3 | 笔记层 | 动态追加 | 待办/日志/每日记录 | 追加式 |
| L4 | 经验层 | 累积进化 | 任务记录/经验档案 | 只追加 |

## 设计原则

1. **权威唯一**：一个事实只有一个权威版本（如"你的画像"只存一份，改版走版本号）
2. **按需加载**：系统层只放每轮必需的，其余检索式加载（不塞爆上下文）
3. **追加不覆盖**：历史记录只增加不删除（回滚/追溯靠它）
4. **成熟固化**：笔记层的活跃内容成熟后 → 固化进知识库层（从"便签"变"档案"）
5. **过时清理**：过时信息标注或归档（防止 AI 重复执行旧想法）

## 记忆生命周期

```
产生（对话/任务）→ 记录（笔记层）→ 成熟（固化进知识库）→ 复用（AI 加载）→ 过时（归档）
```

## 关键：锚点文件

锚点是整个记忆系统的入口——每次对话 AI 先读它，就知道：
- 你是谁（画像在哪）
- 系统怎么运转（恢复流程）
- 现在进行到哪（状态快照）

**锚点坏了 = 系统失忆。所以锚点文件要稳定、可恢复、有版本。**
