## 为什么这样设计

| 层 | 保留策略 | 写入门槛 | 用途 |
|---|---|---|---|
| L1 scratch | 30 天滚动清理 | 无（随手记） | 工作记忆 |
| L2 logs | 按主题归档 | 任务完成即写 | 情景记忆（蒸馏的原料） |
| L3 kb | 永久 | **人工/主代理确认** | 语义记忆（蒸馏产物） |

**核心：蒸馏可审计**——L3 的每条规则都标注来源与确认时间，L2 是 L3 的原料。这就是"越用越强"的闭环：用得越多 → logs 越多 → 蒸馏出更多规则 → 系统越懂你。

## 复现

```bash
sea init                # 生成完整结构
sea add "随手记：..."   # 自动进 L1
sea add "2026-08-15 完成任务"  # 自动进 L2
sea add "规则：..." --level kb # 规则进 L3
sea status              # 查看分层统计
```
