# 长期记忆模板

> 用途：系统记住"正在做的事"——项目、决策、待办。AI 每次对话加载，持续更新。

## 一、当前项目

### 项目：[项目名]
- 状态：[进行中/暂停/已完成]
- 目标：[一句话]
- 关键决策：[记录做过的决定]
- 下一步：[最近要做的事]

## 二、已完成的决策（只追加不覆盖）

- [日期]：[决策内容]（背景一句话）

## 三、待办清单（动态）

- [ ] [事项]（[优先级]）— [备注]
- [ ] ...

## 四、长期事实

- [对你稳定的事实：身份/关系/目标/资产]
- [记录时只写事实，不写推测]

## 五、更新规则

- 项目状态变化 → 更新对应条目
- 新决策 → 追加到"已完成的决策"
- 待办完成 → 标记或移除
- 过期信息 → 标注"已过时"或移除（防 AI 重复执行旧想法）
