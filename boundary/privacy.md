# 隐私与数据卫生

> Self-Evolving Agent 的数据边界设计——系统知道你的越多，越要守规矩。

## 一、数据分级

| 级别 | 内容示例 | 处理 |
|---|---|---|
| 🟢 中性 | 项目/方法/偏好/决策 | 可记录、可复用 |
| 🟡 敏感 | 个人近况/关系细节/财务 | 记录但永不外传 |
| 🔴 绝密 | 健康/隐私/代际信息 | 永不落库（AI 只在你主动提及时接触） |

## 二、数据卫生标准

1. 敏感层永不落库——AI 对话中提到即忘，不写入任何持久存储
2. 中性业务正常记录（这是系统变聪明的原料）
3. 涉及第三方个人信息（如亲友）——默认零提及，用户主动提起才展开

## 三、框架承诺

- 本框架不含任何用户数据——所有模板是空白的
- 你填入的信息只存在你自己的存储里
- 框架更新不读取你的数据

## 四、泄露应对

1. 发现异常操作 → 立即撤回授权/撤销 Token
2. 检查数据分级（是否有敏感信息误入库）
3. 清理 + 重建（系统可回滚）
